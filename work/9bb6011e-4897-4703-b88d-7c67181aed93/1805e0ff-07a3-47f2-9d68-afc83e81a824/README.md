## 如何运行

在此作业目录打开 PowerShell。换机后先创建虚拟环境，再运行两个脚本：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip --version
.\.venv\Scripts\python.exe hello.py
.\.venv\Scripts\python.exe taskbox.py
```

本机已经建好环境，可直接执行最后两条命令，不需要激活虚拟环境。

`taskbox.py` 使用四个命令：

| 命令 | 操作 |
| --- | --- |
| `add` | 再输入任务标题，添加未完成任务 |
| `list` | 列出任务编号、状态和标题；`[ ]` 未完成，`[x]` 已完成 |
| `done` | 再输入从 1 开始的任务编号，将该任务标记为完成 |
| `quit` | 正常退出 |

任务只保存在内存中，退出后清空，符合 S0 要求；本作业尚未实现文件或数据库持久化。

## 代码理解与题目要点

| 代码位置 | 解释 |
| --- | --- |
| `hello.py` 第 1～4 行 | 用标准库 `platform.python_version()` 取得实际版本，然后输出问候语 |
| `taskbox.py` 第 1～6 行 | 定义自己的函数，在函数内新建任务列表；循环读取命令，遇到 `quit` 退出 |
| 第 7～11 行 | 清理标题两侧空格，拒绝空标题，把含标题与完成状态的字典加入列表 |
| 第 12～14 行 | 用**列表推导式**生成显示行；`enumerate(tasks, 1)` 让编号从 1 开始，空列表显示“暂无任务” |
| 第 15～19 行 | 将编号转成整数；先验证范围，再用 `number - 1` 转换成列表索引，只修改对应任务 |
| 第 20～24 行 | 提示未知命令；用 `except ValueError` 处理无效输入，输入结束时捕获 `EOFError` 正常退出 |
| 第 25 行 | 只在直接运行脚本时启动交互，导入模块时不自动读取输入 |

**没有可变默认参数：**`taskbox()` 没有参数，也没有 `=[]`、`={}` 等默认值；`tasks = []` 位于函数内部，每次调用重新创建。自动检查还解析了函数定义，确认没有默认参数。
