## 概念心智模型（要点）

- **同步 = 排队等；异步 = 发起后不干等，腾出时间做别的。** 适合 I/O 密集（等数据库、等网络）。
- **`async` / `await`**：定义协程、等待协程完成。
- **事件循环**：背后调度所有协程的"交通警察"。
- **并发 ≠ 并行**：异步是单线程内的并发（交替），不是多核并行。CPU 密集任务异步帮不上忙（受 GIL 限制，需进程/其他手段）。
- **别混用阻塞调用**：在 async 函数里调用一个阻塞函数，会卡住整个事件循环。

## 常见坑（提纲）

- 在异步代码里调用阻塞 I/O（如同步 `requests`、`time.sleep`）
- 以为异步能加速 CPU 密集计算
- 忘记 `await`，得到一个协程对象而非结果
- 过度异步化——简单场景同步更清晰

## 和 AI 这样协作

- 让 AI 把一个同步端点改成异步，你判断：**改动是否真有必要？有没有残留阻塞调用？**
- 让 AI 解释"这个 await 在等什么、事件循环此刻在做什么"。
