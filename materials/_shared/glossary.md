# 术语表

> 按需查阅。遇到讲义里不懂的词先回这里。

## Python 语言

- **解释器（interpreter）**：运行 Python 代码的程序（CPython 是官方实现）。
- **虚拟环境（venv）**：为每个项目隔离依赖的独立 Python 环境，避免互相污染。
- **包 / 模块（package / module）**：模块是一个 `.py` 文件；包是含多个模块的目录。
- **PyPI**：Python 官方第三方包仓库，`pip`/`uv` 从这里下载库。
- **数据模型（data model）**：Python 用一套"魔术方法"（如 `__len__`、`__iter__`）定义对象行为的机制。
- **鸭子类型（duck typing）**：不看类型，只看对象是否具备所需行为。
- **可变 / 不可变（mutable / immutable）**：`list`/`dict` 可变；`int`/`str`/`tuple` 不可变。影响函数传参与默认参数的坑。
- **推导式（comprehension）**：`[x for x in ...]` 简洁构造列表/字典/集合。
- **装饰器（decorator）**：用 `@` 语法在不改原函数的情况下增强它。
- **类型注解（type hint）**：`def f(x: int) -> str`，供 mypy 静态检查与 IDE/AI 理解。
- **GIL**：全局解释器锁，导致 CPython 多线程不能真正并行跑 CPU 密集代码。

## 后端 / Web

- **HTTP**：浏览器/客户端与服务器通信的协议，基于请求-响应。
- **请求方法**：GET（取）、POST（建）、PUT/PATCH（改）、DELETE（删）。
- **状态码**：2xx 成功、4xx 客户端错误（如 401 未认证、403 越权、404 找不到）、5xx 服务端错误。
- **REST API**：一种以"资源"为中心、用 HTTP 方法操作资源的接口风格。
- **JSON**：前后端交换数据的常用文本格式。
- **端点 / 路由（endpoint / route）**：一个 URL 路径 + 方法对应的处理逻辑。
- **中间件（middleware）**：在请求到达处理函数前后统一处理（如鉴权、日志）。
- **ASGI / WSGI**：Python Web 服务器接口标准；ASGI 支持异步（FastAPI 用 ASGI）。

## 数据

- **SQL**：操作关系型数据库的语言。
- **ORM**：对象关系映射，用 Python 对象操作数据库表，少写 SQL。
- **迁移（migration）**：对数据库表结构变更做版本化管理。
- **事务（transaction）**：一组要么全成功、要么全回滚的数据库操作。
- **N+1 查询**：循环里逐条查库导致的性能陷阱，ORM 常见坑。

## 异步 / 并发

- **同步 / 异步**：同步是排队等待；异步是发起后不等、腾出时间做别的。
- **`async` / `await`**：定义与等待协程的关键字。
- **事件循环（event loop）**：调度协程的核心机制。
- **并发 vs 并行**：并发是"交替处理多件事"；并行是"同时真的一起跑"。

## 安全

- **哈希（hash）**：不可逆地把密码变成摘要存储（用 bcrypt/argon2）。
- **JWT**：一种带签名的令牌，用于无状态认证。
- **注入（injection）**：攻击者把恶意内容拼进 SQL/命令中执行。
- **认证 vs 授权**：认证=你是谁（登录）；授权=你能做什么（权限）。

## 工程

- **测试夹具（fixture）**：pytest 中为测试准备/清理环境的机制。
- **CI**：持续集成，代码提交后自动跑测试/检查。
- **容器（container）/ Docker**：把应用和依赖打包成可移植镜像。
- **环境变量**：在代码外部注入配置（密钥、数据库地址）的方式。
- **12-factor**：一套云原生应用的最佳实践原则。
