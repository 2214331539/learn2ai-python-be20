🌐 HTTP 方法与状态码速查

模块 4 配套参考。设计 REST API 时随手查。

请求生命周期

请求方法（有语义，别乱用）

方法用途幂等？示例
GET读取资源（只读）是GET /tasks
POST新建资源否POST /tasks
PUT整体替换资源是PUT /tasks/1
PATCH部分更新资源否PATCH /tasks/1
DELETE删除资源是DELETE /tasks/1
⚠ 别用 GET 去创建或修改数据 —— 它可能被缓存或被浏览器预取而误触发。

常用状态码

200
OK · 成功
  • GET 查询成功
201
Created · 创建成功
  • POST 新建后返回
204
No Content
  • DELETE 成功、无返回体
400
Bad Request
  • 请求本身不合法
401
Unauthorized · 未认证
  • 没登录 / token 无效
403
Forbidden · 越权
  • 登录了但无权限
404
Not Found
  • 资源不存在
422
Unprocessable
  • 校验失败（FastAPI 默认）
500
Server Error
  • 服务端崩了（别暴露栈）
记忆口诀：2xx 成功 · 4xx 你（客户端）错 · 5xx 我（服务端）错。401 是“你是谁不知道”，403 是“知道你是谁但不让你干”。
