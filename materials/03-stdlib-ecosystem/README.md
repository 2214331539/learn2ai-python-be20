# 模块 3 · 标准库与生态地图

> 统一结构：概念心智模型 → 最小可运行示例 → 常见坑 → 和 AI 这样协作 → 本周任务
> 本文为提纲，课前会补充完整示例。

## 概念心智模型（要点）

- **先问标准库**：很多需求标准库已经解决，不必装第三方。见 [生态地图](../_shared/ecosystem-map.md)。
- **PyPI 与依赖管理**：第三方库从 PyPI 来；加依赖要克制，每个依赖都是维护与安全负担。
- **"选库"是一项核心能力**：面对任务先归类，再在候选里按维护度/文档/依赖取舍。

## 重点标准库（提纲）

- `pathlib` 路径、`json` 读写、`datetime`/`zoneinfo` 时间
- `logging` 日志、`dataclasses` 数据类、`enum` 枚举
- `functools`（`lru_cache`）、`collections`（`Counter`/`defaultdict`）
- `secrets`（安全随机，别用 `random` 做安全）

## 常见坑（提纲）

- 为小功能引入重型库
- 用 `random` 生成安全 token
- 手动拼路径字符串而非用 `pathlib`
- 没有结构化日志，出问题难排查

## 和 AI 这样协作

- 给 AI 一个任务，让它**推荐 3 个候选库并对比**，你用 [生态地图](../_shared/ecosystem-map.md) 的标准核验。
- 警惕 AI 推荐"已停止维护"或"根本不存在"的库——务必核实。

## 本周任务（提纲）

1. 用标准库给贯穿项目加"数据存文件（JSON）"能力，并加日志。
2. 做一次"选库练习"：为某个新需求写一份候选库对比。
3. 附协作记录。
