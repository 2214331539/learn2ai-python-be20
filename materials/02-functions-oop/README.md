## 概念心智模型（要点）

- **一等函数**：函数能作为参数传递、作为返回值、赋给变量。这是装饰器和回调的基础。
- **装饰器**：本质是"接收一个函数、返回一个增强后函数"的函数。后端里到处是它（路由、鉴权、缓存）。
- **类与面向对象**：用类组织"数据 + 行为"。但不要为了用而用——Python 不强制 OOP。
- **`dataclass`**：少写样板代码的轻量数据类。
- **类型注解**：让代码自文档化，也让 mypy / IDE / AI 更懂你的意图。

## 常见坑（提纲）

- 装饰器丢失原函数元信息 → 用 `functools.wraps`
- 过度使用继承，应优先组合
- 把一切塞进一个巨型类
- 类型注解只是提示，运行时不强制校验

## 和 AI 这样协作

- 让 AI **重构**你模块 1 的脚本（提函数、加类型注解），然后你判断：重构后是更清晰还是更啰嗦？
- 让 AI 解释它写的装饰器"到底在哪一步做了什么"。
