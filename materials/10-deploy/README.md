# 模块 10 · 打包与部署

## 概念心智模型（要点）

- **依赖锁定**：部署环境要和开发环境一致，靠锁文件（如 `uv.lock`）保证可复现。
- **容器（Docker）**：把应用 + 依赖 + 运行环境打包成可移植镜像，"在我机器上能跑"不再是问题。
- **配置与代码分离（12-factor）**：密钥、数据库地址等用环境变量注入，绝不写死在代码里。
- **ASGI 服务器**：FastAPI 本身不是服务器，生产用 uvicorn/gunicorn 托管。

## 常见坑（提纲）

- 把 `.env` / 密钥打进镜像或提交进仓库
- 镜像臃肿（没用多阶段构建、没清理缓存）
- 开发配置（debug、SQLite）直接上生产
- 没做健康检查、日志无法收集

## 和 AI 这样协作

- 让 AI 写 Dockerfile 后，审查：**有没有泄露密钥、镜像是否过大、是否以 root 运行。**
- 让 AI 解释每一条 Docker 指令的作用，不要照抄。
