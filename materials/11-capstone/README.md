# 模块 11 · 综合项目周（结课）

> 本模块没有新知识点，目标是整合与独立实战。

## 目标

在限定时间内，独立地、借助 AI，为贯穿项目**添加一个全新功能**，并做技术答辩，讲清每一个决策"为什么这么做"。

## 可选新功能（任选其一，或自拟）

- **任务提醒**：到期任务的查询/标记逻辑（加分：定时任务）。
- **书签标签统计**：按标签聚合统计，返回图表所需数据。
- **全文搜索**：对任务/书签标题做关键字搜索。
- **数据导出**：把用户数据导出为 JSON/CSV。

## 要求（整合前面所有模块）

- 有数据校验（模块 5）、持久化（模块 6）、认证授权（模块 8）。
- 有针对新功能的测试（模块 9），通过 ruff + mypy。
- 能容器化运行（模块 10）。
- 全程遵循 [AI 协作检查清单](../_shared/ai-collaboration-checklist.md)。

## 技术答辩（本课精髓）

准备 5–8 分钟讲清：

1. 需求怎么拆解的？数据怎么流动？
2. 关键处你**让 AI 做了什么、又否决/修改了什么**？
3. 你如何验证正确性与安全性？
4. 如果重做，你会怎么改进？

> 评分看的是**你的判断、验证与表达**，而不是代码行数或是否全部自己手写。

## 交付物

- 一份 README：如何运行 + 架构说明。
- 一份完整的 AI 协作记录。
