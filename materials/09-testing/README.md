# 模块 9 · 测试与质量

> 统一结构：概念心智模型 → 最小可运行示例 → 常见坑 → 和 AI 这样协作 → 本周任务
> 本文为提纲，课前会补充完整示例。

## 概念心智模型（要点）

- **测试是给未来的你和 AI 的安全网**：改代码后，测试告诉你有没有改坏。
- **好测试测行为，不测实现**：关注"输入→输出"，而非内部细节。
- **夹具（fixture）**：pytest 中准备/清理测试环境（如临时数据库）的机制。
- **静态检查**：ruff（lint + 格式化）、mypy（类型）在代码跑之前就能抓错。
- **覆盖率是参考不是目标**：100% 覆盖率不等于没 bug。

## 最小可运行示例（待补充）

- pytest 测一个纯函数
- 用 fixture + 测试数据库测 API 端点
- 参数化测试多组输入
- 跑 ruff / mypy

## 常见坑（提纲）

- 测试依赖真实外部服务/生产库
- 只测"快乐路径"，不测错误与边界
- **AI 写的测试"假通过"**：测试写得太宽松，怎么都过——等于没测
- 测试之间互相依赖、有顺序要求

## 和 AI 这样协作（关键判断力训练）

- 让 AI 为端点写测试，你重点判断：**这些测试是真的在验证行为，还是只是"摆样子"？**
- 故意在业务代码里埋一个 bug，看 AI 写的测试能不能抓到——抓不到说明测试无效。
