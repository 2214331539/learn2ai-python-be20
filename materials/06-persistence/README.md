## 概念心智模型（要点）

- **持久化**：数据要存到数据库，重启不丢。开发用 SQLite，生产常用 PostgreSQL。
- **SQL 基础**：表、行、主键、外键、增删改查。
- **ORM**：用 Python 对象操作表，少写 SQL；但你仍需能看懂它生成的 SQL。
- **迁移（Alembic）**：表结构变更要版本化，不能手改生产库。
- **事务**：一组操作要么全成、要么全回滚。

## 常见坑（提纲）

- **N+1 查询**：循环里逐条查库，性能灾难
- **SQL 注入**：拼接 SQL 字符串（务必参数化）
- 会话未正确关闭/提交，导致连接泄漏或数据没落库
- 直接改生产库结构而不走迁移

## 和 AI 这样协作

- 让 AI 写 CRUD 后，重点审查：**有没有字符串拼 SQL、有没有 N+1、会话是否正确管理**。
- 让 AI 把它生成的 ORM 查询"翻译成实际 SQL"给你看，判断效率。
