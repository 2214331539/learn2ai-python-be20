## 概念心智模型（要点）

- **HTTP 是请求-响应**：客户端发请求（方法 + 路径 + 头 + 体），服务器返回响应（状态码 + 头 + 体）。
- **REST 风格**：以"资源"为中心，用 GET/POST/PUT/PATCH/DELETE 操作资源。
- **状态码会说话**：2xx 成功 / 4xx 客户端错 / 5xx 服务端错。正确用状态码是基本素养。
- **FastAPI 心智**：一个路由 = 一个函数 + 一个装饰器（`@app.get("/tasks")`）。
