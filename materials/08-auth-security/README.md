# 模块 8 · 认证与安全（重点模块）

> 统一结构：概念心智模型 → 最小可运行示例 → 常见坑 → 和 AI 这样协作 → 本周任务
> 本文为提纲，课前会补充完整示例。本模块是 AI 代码安全审查训练的重点。

## 概念心智模型（要点）

- **认证 vs 授权**：认证=证明"你是谁"（登录）；授权=决定"你能做什么"（权限）。两者都要做。
- **密码绝不明文存储**：用成熟哈希算法（bcrypt / argon2）+ 加盐。
- **JWT**：一种带签名的令牌，服务端无需存会话即可验证身份。
- **纵深防御**：输入校验、参数化查询、最小权限、密钥隔离，层层设防。

## 最小可运行示例（待补充）

- 注册：密码用 passlib(bcrypt) 哈希后存库
- 登录：校验密码，签发 JWT
- 受保护端点：校验 JWT
- 授权：确保用户只能操作"自己的"数据

## 常见坑（后端高频漏洞，务必记住）

- **越权**：只检查"登录了没"，没检查"这条数据是不是他的"（IDOR）。
- **SQL 注入**：拼接 SQL。
- **密码处理错误**：明文、md5、未加盐。
- **密钥硬编码**：把 JWT secret / 数据库密码写进代码提交到仓库。
- **敏感信息进日志**：日志打印密码、token。
- **错误信息泄露**：把内部栈追踪直接返回给客户端。
