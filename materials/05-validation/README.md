# 模块 5 · 数据校验与建模

> 统一结构：概念心智模型 → 最小可运行示例 → 常见坑 → 和 AI 这样协作 → 本周任务
> 本文为提纲，课前会补充完整示例。

## 概念心智模型（要点）

- **永远不要信任外部输入**：所有进入系统的数据都要先校验。
- **类型驱动开发**：用 Pydantic 模型声明"数据应该长什么样"，校验自动完成，还自带文档。
- **输入模型 vs 输出模型**：接收的数据和返回的数据往往不同（如返回时不含密码）。

## 最小可运行示例（待补充）

- 用 Pydantic 定义 `TaskCreate` / `TaskOut`
- 字段约束（必填、长度、范围、枚举）
- 校验失败时 FastAPI 自动返回 422

## 常见坑（提纲）

- 把数据库模型直接当接口返回，泄露敏感字段
- 校验逻辑散落在各处而非集中在 schema
- 对可选字段与默认值处理不当

## 和 AI 这样协作

- 让 AI 根据你的需求设计 Pydantic 模型，你重点审查：**约束是否完整、有没有泄露敏感字段**。
- 故意发非法数据，验证校验是否真的拦住了。
