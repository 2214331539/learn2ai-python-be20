# 作业一 · 搭好环境，跑通第一个脚本（并学会和 AI 协作）

本作业对应 [模块 0 · 环境与工作流](../../materials/00-setup/README.md)，顺带用到 [模块 1 · Python 语言精要](../../materials/01-language/README.md) 的一点内容。

这是本课的"开张"作业。目标有两个：一是把开发环境真正搭起来、跑通，二是**第一次按本课的方式和 AI 协作**——AI 出草稿，你来读懂、验证、把关。本课从第一份作业起就考核你的判断力，而不是代码出自谁之手。

## 背景

本学期我们会围绕一个贯穿项目——"个人任务/书签 API 服务"——逐周迭代（见 [项目说明](../../materials/project/README.md)）。本周先把地基打好：装好 Python 与 `uv`、建好项目目录、用 Git 管理、跑通第一个脚本。

## 你要做的事

1. **装好环境**：Python 3.11+ 与包管理工具 `uv`（也可用传统 `python -m venv` + `pip`，但推荐 `uv`）。
2. **建项目并用 Git 管理**：创建贯穿项目目录，`git init`，配好一个合理的 `.gitignore`（至少排除虚拟环境、`__pycache__`、`.env`）。
3. **写并跑通 `hello.py`**：打印当前 Python 版本，并额外打印一行你自己的内容。
4. **写一个 15–25 行的小脚本 `taskbox.py`**（贯穿项目的 S0 雏形）：
   - 用内存里的 `list` 存"任务"；
   - 支持三个操作：添加任务、列出所有任务、把某个任务标记为完成；
   - 至少用到：一个**推导式**、一次**异常处理**、一个你自定义的**函数**；
   - 代码里**不能有"可变默认参数"的坑**（见模块 1 常见坑）。
5. **完成一次 AI 协作**：以上代码可以让 AI 帮你写，但你必须能逐行解释、并亲自跑通验证。

## 提交内容

把成果放在 `work/<你的用户UUID>/1805e0ff-07a3-47f2-9d68-afc83e81a824/` 下，至少包含：

- `hello.py`、`taskbox.py`、`.gitignore`；
- 一个 `README.md`，写明：如何运行你的脚本、运行截图或输出结果；
- 一段 **AI 协作记录**（3–6 句，见下）。

> 成果由应用用你已连接的 GitHub 身份提交并请求分享确认，你**不需要自己 `git push`**。

## AI 协作记录（必写，占重要评分）

请按 [AI 协作检查清单](../../materials/_shared/ai-collaboration-checklist.md) 的要求，简要写明：

1. 你让 AI 做了什么（关键提示大意）；
2. AI 给的方案你**改了 / 否决了**哪里，为什么；
3. 你做了哪些**验证**（跑了什么、测了什么边界）；
4. 特别说明：你是如何确认代码里**没有**"可变默认参数"坑的。

## 评分标准（共 100 分）

- **环境与工程规范（25 分）**：Python/uv 装好并能运行；`.gitignore` 合理；目录结构清晰。
- **脚本功能正确（30 分）**：`hello.py` 与 `taskbox.py` 能跑通；三个操作都正确工作。
- **语言要点落实（20 分）**：正确使用推导式、异常处理、自定义函数；避开可变默认参数坑。
- **AI 协作记录质量（25 分）**：记录真实、具体，体现出你读懂了代码、做了有效验证与判断——**这部分坦诚写不会扣分，隐瞒或空洞才会**。

## 提示

- 遇到环境/版本报错，把**完整报错 + 你运行的命令 + 操作系统**一起发给 AI，别只说"装不上"。
- 先读懂再运行 AI 给的任何代码；解释不出来的行，就是你本周要补的知识点。
