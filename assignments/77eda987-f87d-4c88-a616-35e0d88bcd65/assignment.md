# 作业二 · 吃透 Python 语言特性（读懂 + 改写）

对应 [模块 1 · Python 语言精要](../../materials/01-language/README.md)。

本作业在作业一的 `taskbox.py` 基础上深化，重点不是"写更多代码"，而是**真正理解 Python 的几个核心特性，并能看穿常见坑**。

## 背景

作业一你已经有了一个能添加/列出/完成任务的 S0 脚本。这次我们让它更"Pythonic"，并通过一组阅读与改错练习，检验你对可变/不可变、推导式、异常的理解。

## 你要做的事

1. **扩展 `taskbox.py`**：
   - 用**推导式**实现"按关键字筛选任务"和"统计未完成数量"；
   - 定义一个**自定义异常类**（如 `TaskNotFound`），在找不到任务时抛出并在调用处优雅处理（EAFP 风格）；
   - 任何需要默认集合的参数都不得使用可变默认值。
2. **阅读理解（写进 README）**：挑你脚本中最"费解"的 3 行代码，逐行解释它在做什么、为什么这么写。
3. **改错练习**：在 `bugs.py` 里放入下面两类各一个"坏例子"并修正，附注释说明错在哪：
   - 可变默认参数坑；
   - `is` 与 `==` 用错的坑。
