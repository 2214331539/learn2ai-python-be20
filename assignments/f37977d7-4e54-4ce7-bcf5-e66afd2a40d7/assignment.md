# 作业十二 · 结课项目：独立实现一个新功能（S8）

对应 [模块 11 · 综合项目周](../../materials/11-capstone/README.md)，项目阶段 **S8**。

这是结课作业。目标：在限定时间内，**独立地、借助 AI**，为贯穿项目添加一个全新功能，并做技术答辩，讲清每个决策"为什么这么做"。

## 你要做的事

1. **任选一个新功能**（或自拟）：任务提醒 / 书签标签统计 / 全文搜索 / 数据导出。
2. 新功能必须整合前面所学：**数据校验**（Pydantic）、**持久化**（SQLAlchemy）、**认证授权**（只能操作自己的数据）。
3. 为新功能写 **pytest 测试**，并通过 **ruff + mypy**。
4. 能 **容器化运行**。
5. 准备一份 5–8 分钟的**技术答辩**要点（写进 README 即可）：需求如何拆解、数据如何流动、AI 做了什么又否决了什么、如何验证正确性与安全性、若重做会怎么改进。

## 提交内容

放在 `work/<你的用户UUID>/f37977d7-4e54-4ce7-bcf5-e66afd2a40d7/`：

- 可运行的项目代码（含新功能 + 测试 + Dockerfile）；
- `README.md`：如何运行 + 架构说明 + 技术答辩要点；
- 完整的 AI 协作记录。

> 成果由应用用你的 GitHub 身份提交并请求分享确认，你不需要自己 `git push`。

## 评分标准（100 分）

- 新功能可用，正确整合校验/持久化/认证授权（35 分）
- 测试有效、通过 ruff + mypy（20 分）
- 可容器化运行（10 分）
- 技术答辩要点清晰，能讲清每个决策的"为什么"（20 分）
- AI 协作记录真实、体现判断力（15 分）

## 提示

- 评分看的是你的**判断、验证与表达**，而不是代码行数或是否全部手写。
- 全程遵循 [AI 协作检查清单](../../materials/_shared/ai-collaboration-checklist.md)。
