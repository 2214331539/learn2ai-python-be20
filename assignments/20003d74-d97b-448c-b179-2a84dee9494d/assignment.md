# 作业四 · 标准库持久化 + 一次“选库”调研

对应 [模块 3 · 标准库与生态](../../materials/03-stdlib-ecosystem/README.md)。

本作业两件事：一是用**纯标准库**给项目加持久化与日志（体会"自带电池"），二是做一次**选库调研**（训练面对任务时的工具选择与核实能力）。

## 你要做的事

1. **标准库持久化**：用 `pathlib` + `json` 让 `taskbox` 把数据存到文件、启动时读回；用 `logging` 记录关键操作（不要用 `print`）。
2. **标签统计**：用 `collections.Counter` 统计各标签出现次数。
3. **选库调研**（写进 `library-research.md`）：为一个具体新需求（例如"定时清理 7 天前完成的任务"）让 AI 推荐 **2–3 个候选库**并对比（适用场景 / 维护活跃度 / 依赖重量 / 是否标准库就能解决）。你需**亲自到 PyPI 或官方文档核实**每个候选是否真实存在、是否仍在维护，并记录核实结果。

## 提交内容

放在 `work/<你的用户UUID>/20003d74-d97b-448c-b179-2a84dee9494d/`：

- 代码（持久化 + 日志 + 标签统计）、`library-research.md`、`README.md`（运行说明）；
