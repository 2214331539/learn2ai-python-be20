# 作业五 · 你的第一个 API（FastAPI S1）

对应 [模块 4 · HTTP 与第一个 API](../../materials/04-http-api/README.md)，项目阶段 **S1**。

贯穿项目正式"上线"：把命令行脚本变成一个 HTTP 服务。

## 你要做的事

1. 用 **FastAPI** 实现 `GET /tasks`、`POST /tasks`、`GET /tasks/{id}`，数据先存内存。
2. **正确使用状态码**：创建成功返回 `201`，查询不存在的任务返回 `404`（不要一律返回 200）。
3. **亲自验证**：打开自动生成的 `/docs`，把每个端点都点一遍，记录每次请求的状态码与返回（截图或文字）。
4. 遵循 REST 资源语义（用 `/tasks` 而非 `/getTasks`）。

## 提示

- HTTP 是无状态的：内存里的数据重启就没了，这正是下个模块要解决的问题。
- 别用 GET 去创建或修改数据。
